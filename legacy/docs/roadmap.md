# Release Roadmap & Tasks

این نقشهٔ راه برای رساندن بازی به یک نسخهٔ تک‌نفره پروتوتایپ و سپس مولتی‌پلیر آماده انتشار است.

M1 — Prototype (1-2 weeks)
- Player movement, jump, slide, melee attacks
- Basic enemy spawn & simple AI
- Weapon pickups and basic shooting
- One playable level
- Save/Load progress

M2 — Polish & UI (2 weeks)
- HUD polishing
- Controls tuned for mobile
- Visual FX and particles
- Sound effects

M3 — Multiplayer (3-4 weeks)
- Photon integration
- Lobby & matchmaking
- Sync player states & items
- Chat & voice using Photon Voice

M4 — Optimization & Android Build (2 weeks)
- LODs, texture atlasing, batching
- Memory & GC tuning
- Build AAB and test on devices

M5 — QA & Release (1-2 weeks)
- Bug fixing
- Store assets & screenshots
- Prepare release
